# 旅日手帖｜日本旅行規劃網站

📱 **線上體驗網址**：[https://yaoan2026.github.io/japan-travel-planner/](https://yaoan2026.github.io/japan-travel-planner/)

手機優先的日本旅遊規劃網站（純 HTML/CSS/JS，免安裝任何後端或套件，支援 PWA 離線使用與加入手機主畫面）。

## 功能
- **⚡ 一鍵規劃行程**：選城市（可多選，依順序）、出發日期、天數、步調、興趣 → 自動分配每城市天數，依距離就近排景點、安排午晚餐與點心、城市間交通、首日抵達/末日返程；附季節提醒、票券建議與預估花費。可換一組、刪除/替換景點、儲存、分享、列印。
- **🚄 交通**：機場交通、市內交通、IC 卡、各地票券（JR Pass、Tokyo Subway Ticket、大阪周遊卡…）、城市間交通、必備 App、搭車禮儀。
- **🍜 美食**：7 個地區必吃美食、推薦店家，一鍵查 Google 地圖與 Tabelog。
- **🗺️ 地圖**：景點/美食分類地圖、行程每日路線、定位。
- **🎁 優惠**：退稅制度、藥妝/百貨優惠券、門票平台、eSIM、信用卡、換匯。
- **🧰 工具**：即時匯率換算、7 天天氣、實用日語（可發音）、緊急電話、行前清單。
- 支援「加入主畫面」（PWA），資料存在手機瀏覽器本機。

涵蓋地區：東京、大阪、京都、奈良、北海道（札幌・小樽）、福岡、沖繩。景點與美食資料都在 `data.js`，可自行增修。

## 如何在手機上打開
最簡單：部署到免費靜態網站空間，取得 https 網址後用手機開啟。
1. **Netlify Drop**：到 https://app.netlify.com/drop ，把整個資料夾拖進去即可取得網址。
2. **GitHub Pages**：上傳到 GitHub repo → Settings → Pages → 選 main 分支。

同一個 Wi-Fi 下臨時測試：
```powershell
cd d:\日本旅行規劃
python -m http.server 8000
```
手機瀏覽器開 `http://<電腦的 IP>:8000`（定位與離線功能需 https 才能使用）。
